# TradeBridge India – AI-Powered Export Learning Platform

## Overview
TradeBridge India is an educational web platform designed to simplify export-import (EXIM) learning for MBA students, aspiring exporters, and small businesses. It brings export-related resources, practical case studies, trade updates, quizzes, and export planning tools into one accessible website.

**Live Website:** https://tradebridgeindia.netlify.app

## Key Features
- **Ask TradeBridge AI Agent:** Conversational assistance for export-import queries using Google Gemini and Google Search grounding, with fallback knowledge sources.
- **EXIM Quiz:** Interactive quizzes to test understanding of export-import concepts.
- **EPC Explorer:** Information about Export Promotion Councils.
- **Trade Glossary:** Beginner-friendly explanations of international trade terminology.
- **Case Studies:** Practical examples of EXIM concepts and trade-related situations.
- **Global Trade & Geopolitics:** Trade developments and geopolitical information relevant to exporters.
- **Export Journey Risk Assessment:** An indicative 16-factor framework for evaluating shipment-related financial, logistics, market, and geopolitical risks.

## AI Agent
The Ask TradeBridge agent is designed to answer export-related questions, retrieve relevant information from available knowledge sources, and present explanations in a structured, accessible format. The implementation includes fallback handling and source references to help users verify important information.

## Purpose
To make export-related knowledge easier to discover and understand by combining educational resources, interactive learning, and AI-assisted information retrieval in one platform.

## Disclaimer
The platform is an educational project. Its AI-generated responses and risk assessments should not be treated as official legal, financial, customs, or export-compliance advice. Users should verify current requirements through authoritative sources.
